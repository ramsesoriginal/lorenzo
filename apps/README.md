# apps/

One directory per deployable application, named by purpose, not type. There is no fixed slot per "kind" of app — there can be one or many web frontends, multiple mobile apps, one or more Discord bots, side by side. This table is the list of every app; each app's README says what it does in detail and how to run it.

See [ADR 0007](../docs/adr/0007-apps-layout-and-multiplicity.md) for the reasoning and [docs/guides/adding-an-app.md](../docs/guides/adding-an-app.md) for how to add one. The static web apps share the stack of [ADR 0004](../docs/adr/0004-static-astro-frontend.md): Astro and plain TypeScript, no component framework.
