# RFCs

For proposals that aren't decided yet — bigger than an ADR captures, or genuinely open questions. An RFC becomes one or more ADRs once decided (or gets dropped).

To start one: copy an [ADR](../adr/0000-template.md)'s structure but title it "RFC: \<question\>" and leave Decision open until there's consensus.

- [0026 - World-model axes: an entity's full address beyond physical containment](0026-world-model-axes-and-address.md) — proposed, Decision open; designs the five non-containment axes of [docs/domain/world-model.md](../domain/world-model.md) (space, sphere, plane, timeline, multiverse), how an entity's full address composes with `containment`, and portals as connection entities, via a structured three-round, eight-perspective debate; converges on a shared baseline (frames are entities, nothing seeded, placement inherits down containment, never feeds ADR 0046 GM reachability, viewer-relative player reads, inventory never timeline-filtered) and two candidates — a fixed platform axis set vs. an axis registry shaped so tenant-defined axes stay reachable — with four named disagreements and eight verbatim dissents preserved; leaves time/causality open as a precisely shaped three-part question; also surfaces a real cross-tenant FK gap in shipped code (single-column `entity` FKs checked without RLS) and makes a composite-tenant-FK retrofit its prerequisite
- [0027 - LorenzoScript: a Markdown dialect, renderer, and editor for information text](0027-lorenzoscript.md) — accepted, decided with the maintainer; a CommonMark-based dialect for `payload_description.content` with entity links by slug (`[[Ashfang]]`, `[text](being/ashfang)`, the prefix a view hint), `{{ }}` class blocks and directives (`{{TOC}}`, `{{date}}`, reserved `{{cal}}`), MathML math, and no raw HTML; two zero-dependency packages (`packages/lorenzoscript`, `packages/lorenzoscript-editor`) sharing one syntax tree, one set of spec test files also binding the Python reference extractor; accepts RFC 0015's `entity_slug` slice and adds a batch slug-resolve endpoint; seven stages, each with its own ADR
