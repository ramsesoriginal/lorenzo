Keep track of worlds.

Lorenzo is world, campaign, and character bookkeeping for game masters, players, authors, and worldbuilders — from a single D&D one-shot to a five-author shared multiverse.

“Scholar, not wizard. Archivist, not administrator. Worlds, not fantasy worlds.”

Color system

Ink and Paper carry the interface. Archive Blue drives interaction. Medici Gold is punctuation, not a surface — identity.md §6.3 puts it at roughly 2–5% of a screen. These seven primitives are identity-level; product code styles against the semantic roles below.

Semantic roles

identity.md §6.6: primitives don't get used directly — every app reaches for the same surface/text/border/action/status roles instead. Burgundy is destructive/dangerous and genuinely dramatic emphasis only — never secrecy. Restricted visibility (private, GM-only, a selected group) is deliberately color-neutral; only the icon says which tier it is, and public needs no badge at all.

Supporting graphic language

The spark reappears beyond the logo only for canonical markers and rare editorial punctuation — per identity.md §7.1, its value comes from scarcity, so it is deliberately not used here as a repeating divider or loading motif (§17 covers what is: ordinary interface icons). Elsewhere, Lorenzo's visual vocabulary is nodes, paths, and relationships: information architecture, not treasure maps (§7.2).

Information architecture, not treasure maps.

Mascot

Personality lives in illustration; the core mark stays disciplined. The mascot appears in onboarding, empty states, and community moments — never as a stand-in for the logo.

Lorenzo

An androgynous worldkeeper and archivist — sidecut, blue-tipped hair, blue eyes, contemporary scholarly styling. Reads as a person who maintains worlds, not a fantasy wizard.
