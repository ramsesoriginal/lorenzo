# 0006 - License: AGPL-3.0

Status: accepted

## Context

This is a public showcase project, but it's also shaped exactly like a thing someone could take and resell as a closed SaaS without contributing anything back — a multi-tenant campaign-management API is a product, not just a library.

## Decision

AGPL-3.0. Unlike GPL, its network-use clause means running a modified version as a hosted service still triggers the obligation to publish source to that service's users — not just to people who receive a distributed binary.

## Consequences

- Some potential contributors/companies avoid AGPL code on principle — accepted tradeoff.
- Any future `packages/` library genuinely meant for reuse outside this project (per [0003](0003-polyglot-monorepo-tooling.md)) may warrant its own, more permissive license — that's a per-package decision when it happens, not a change to this one.
