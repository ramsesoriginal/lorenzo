# Lorenzo v1.0

Lorenzo has a goal state for v1. This table is it: what the system can do across all of its applications once v1 ships. This is a documentation snapshot audited against merged code on 2026-11-09; live execution status belongs to the linked issues and milestones. “Partial” means some of the row is implemented, with the remainder stated explicitly. The tracking checklist is [#376](https://github.com/ramsesoriginal/lorenzo/issues/376); a Notes entry says what already exists for a row that is not done, and where the decision is recorded for one that is.
