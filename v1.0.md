# Lorenzo v1.0

Lorenzo has a goal state for v1. This table is it: what the system can do across all of its applications once v1 ships. Status is as of 2026-10-04; the row on tenant deletion, abuse limits and the stat tie-break order was corrected on 2026-10-11. The tracking checklist is [#376](https://github.com/ramsesoriginal/lorenzo/issues/376); a Notes entry says what already exists for a row that is not done, and where the decision is recorded for one that is.
